Build MCP tools from the APIs you already have. Control what every agent can do.

One binary on your machine, between your agents and your APIs, old ones too. Import an API like in Postman, write tools in a few lines of TypeScript, and give each agent its own toolkit and access. Credentials stay with mcpDeck; agents never see them.

Install

In PowerShell. Installs for your user, no admin needed, and adds mcpdeck to your PATH:

irm https://github.com/abhijeet-oxide/mcpDeck/releases/latest/download/install.ps1 | iex

Or download mcpdeck_windows_amd64.exe and double-click it. It starts and opens in your browser. From a terminal:

curl.exe -LO https://github.com/abhijeet-oxide/mcpDeck/releases/latest/download/mcpdeck_windows_amd64.exe

Releases aren't code-signed yet, so SmartScreen may ask you to confirm: More info › Run anyway. ARM: replace amd64 with arm64.

Installs to ~/.local/bin after checking the download against the release checksums:

curl -fsSL https://github.com/abhijeet-oxide/mcpDeck/releases/latest/download/install.sh | sh

Or just the binary (Apple silicon; darwin_amd64 for Intel):

curl -fLo mcpdeck https://github.com/abhijeet-oxide/mcpDeck/releases/latest/download/mcpdeck_darwin_arm64 && chmod +x mcpdeck && ./mcpdeck

Or just the binary, with wget (linux_arm64 for ARM):

wget -O mcpdeck https://github.com/abhijeet-oxide/mcpDeck/releases/latest/download/mcpdeck_linux_amd64 && chmod +x mcpdeck && ./mcpdeck

Then run mcpdeck. The UI opens at http://127.0.0.1:47800. To look around first, mcpdeck dev starts a demo with sample APIs, tools and agents. Pin a version with MCPDECK_VERSION=v0.1.0. Every file has a checksum and provenance attestation.

What it does

Any HTTP API, old ones too

Paste a Swagger page URL, import OpenAPI or a Postman collection, or paste curl. XML bodies, form posts and cookie logins work.

Tools in a few lines of TypeScript

Chain requests across systems, run them in parallel and return only what's needed, with autocomplete for every API you added.

One MCP server per toolkit

Add a toolkit to Claude Code, VS Code, Cursor or Claude Desktop in a click. An agent sees only the toolkits it's given.

One set of keys, separate agents

Credentials are stored once, encrypted, and added to requests on the way out. Agents use them without ever seeing them.

Read-only means read-only

Give an agent read access and the proxy refuses POST, PUT, PATCH and DELETE, whatever a tool tries.

Every call recorded, then improved

Time and tokens per call, per agent, turned into suggestions: merge calls, trim outputs, run in parallel. You approve each one.

Three steps

Add an API

APIs › Import. Paste a Swagger page URL or drop a file. Send a few requests and save the good responses.

Build a tool

Select requests in History › Create tool, or write it in the editor. Test, save. It's live as a new version.

Give it to an agent

Toolkit › Add to › Claude Code. Read-only by default; allow writes or building per agent.
